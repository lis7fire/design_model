# design_model
Java设计模式研究-GoF23

面向对象三大特性：继承、多态、封装。
接口和抽象类主要区别：
1. 接口没有构造器方法
2. 接口方法若实现，必须加上default或者static
3. 默认public权限。
4. 接口：has-a能力。抽象类：is-a关系。优先用接口。

OOP七大原则
1. 开闭原则：根本原则，下面其他的原则是围绕此目标的实现。
2. 里氏替换原则：子类继承父类，不要修改父类原有方法。只做扩展。
3. 依赖倒置：面相接口，不要面向实现
4. 单一职责：类的职责单一。粒度控制，提高内聚
5. 接口隔离原则：一个接口不要放太多无关的方法。
6. 迪米特法则：降低程序耦合度。
7. 合成复用原则：先用组合（has-a）、聚合等，其次考虑继承。

三大类：对应项目三个模块：Creational、Structural、Behavioral
1. Creational-创建型模式：用于创建对象，共享、复用、节省资源
2. 结构型模式：用于处理类和对象之间的组合关系，实现更灵活，更可维护的代码结构
3. 行为型模式：关注对象之间的通信和协作，以实现更高级别的功能
